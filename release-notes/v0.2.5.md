# Smoother playback and clearer loading

- Linux original-file playback now sets a larger, bounded WebKit media buffer automatically. This fixes the reproduced MKV buffering stall without user setup, server conversion, or media changes.
- AppImage includes its media framework and codecs. Packaged-runtime checks verify audible H.264/AAC MP4 and H.264/AC-3 MKV playback, including the shipped binary's automatic startup defaults.
- Fullscreen playback hides the desktop title bar.
- Paused video shows a central Resume button. Clicking the video reliably pauses/resumes, including through the control overlay; double-click fullscreen and menus remain usable.
- Intro/outro markers use a quieter rail below the seek bar and stay within the timeline.
- A small animated loading indicator shows how many servers still have work pending while already-loaded content stays available.
- Playback errors no longer ask users to run terminal commands.

Windows installer/portable and Linux AppImage/Debian packages are included. Direct play remains mandatory: no server transcoding or remuxing fallback is enabled.
