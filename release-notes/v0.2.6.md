# 0.2.6

- Linux playback now uses an embedded native video surface, fixing original-file playback failures caused by the webview's handling of MKV files and image subtitles.
- The AppImage includes the required native playback components; the Debian installer declares the matching dependencies.
- Keeps Zenith's player controls, resume position, audio selection, subtitle preferences, playback speed, fullscreen and mini player.
- Fixes native end-of-file handling so replay and the next episode work reliably.

Playback continues to use the original file. Server transcoding remains disabled.
