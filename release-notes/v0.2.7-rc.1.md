# Linux rendering compatibility candidate

- Applies the upstream version-aware WebKitGTK renderer workaround automatically before the interface starts. Older WebKit versions use the established compatibility path; 2.54 and newer preserve compositing with full shared-memory frames so transparent player controls do not lose unchanged pixels.
- Preserves explicitly configured renderer options and keeps native original-file video decoding. Server transcoding remains disabled.
- Adds coverage of the actual Zenith player UI, detailed moving video, menus and repeated title changes alongside the existing audio, subtitles, seeking, fullscreen and replay checks.

This is a Linux validation candidate for the reported flickering/black-screen regression. It has not yet been confirmed on the affected Intel Iris Xe computer. The stable 0.2.6 release is unchanged.
