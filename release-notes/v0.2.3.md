# Direct play and Windows audio

- Playback uses the original file and quality only. Server transcoding, server remuxing, conversion retries and quality settings that request conversion are disabled, including preferences saved by older versions.
- Codec and container support is checked instead of unconditionally advertising MKV and audio formats. Unsupported original files show an explanation rather than silently starting conversion.
- Image subtitles cannot trigger server burn-in. Use text subtitles or turn subtitles off for direct play.
- Windows app audio renders captured, decoded sound through Zenith's own process, addressing the WebView2 process separation that prevents some application-window screen shares from including sound. Volume, mute, pause, seek and closing playback are preserved, with bounded queues and normal audio fallback if native output is unavailable. The option is in Settings > Playback.
- Movie rating stars and scores are aligned together.

Validated with JavaScript regressions, browser playback and real AudioWorklet checks, Rust tests and a silent Windows output-device check. Capture in a live Discord call has not been independently verified.
