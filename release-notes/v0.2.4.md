# Linux playback codec support

- Ubuntu/Debian packages now declare the local GStreamer decoder and media-plugin dependencies needed for original-file playback, including H.264/AC-3 MKV files.
- AppImage packaging includes the GStreamer media framework and checks that its decoder/demuxer plugins are present.
- Linux decoding errors explain which local media packages to install, show the file codecs and provide a copyable install command.
- Late responses or failures from an older playback request cannot replace the newer stream or its error state.
- Direct play remains mandatory. No server transcoding, remuxing or conversion fallback is enabled.
- Linux builds now verify real WebKitGTK playback of local H.264/AAC MP4 and H.264/AC-3 MKV samples and inspect the resulting package dependencies.

Install the .deb with your package manager or `sudo apt install ./Zenith_0.2.4_amd64.deb` so its codec dependencies are installed. Fully restart Zenith after adding codecs.
