# Faster media navigation

- Home and media libraries show results from each server as they arrive instead of waiting for every connected server.
- Movie pages show playback controls before fetching recommendations and other-server copies.
- Genre menus and episode lists load separately from the main page.
- Repeated Jellyfin reads share requests and use a five-second cache. Writes clear the cache, and responses remain separated by server and sign-in.
- Late responses from a page you have left cannot overwrite the next page.

Validated with the JavaScript regression suite and a browser test using local fake media and an unresponsive secondary server, including successful video playback.
